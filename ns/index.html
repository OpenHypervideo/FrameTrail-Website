1. Overview

FrameTrail is an open-source hypervideo platform for creating interactive, annotated videos with overlays, annotations, code snippets, and linked resources.

FrameTrail's data model extends the W3C Web Annotation Data Model with additional properties needed to describe hypervideo-specific concepts: spatial positioning of overlays, resource typing, thumbnail references, licensing metadata, timed code execution, and type-specific attribute bags.

This namespace — http://frametrail.org/ns/ — defines those extension terms. It is intended to be used alongside the W3C annotation context (http://www.w3.org/ns/anno.jsonld) as shown in the examples below.

2. JSON-LD Context

A JSON-LD context document is available at http://frametrail.org/ns/context.jsonld. It can be included in the @context array of any Web Annotation document: 

{
  "@context": [
    "http://www.w3.org/ns/anno.jsonld",
    "http://frametrail.org/ns/context.jsonld"
  ],
  "type": "Annotation",
  …
}

Alternatively, the prefix can be declared inline (this is the pattern currently used in FrameTrail's codebase): 

{
  "@context": [
    "http://www.w3.org/ns/anno.jsonld",
    { "frametrail": "http://frametrail.org/ns/" }
  ],
  …
}

When this namespace URL is requested with Accept: application/ld+json, the server returns the context document directly (see Content Negotiation).

3. Vocabulary

All terms are properties in the http://frametrail.org/ns/ namespace. The Context column indicates where in a Web Annotation object the property appears.

Term IRI Context Expected Type Description
frametrail:type …ns/type Annotation / Body String Classifies the FrameTrail item. On the annotation level, values are Annotation, Overlay, or CodeSnippet. On the body level, values identify the resource subtype (see §4).
frametrail:name …ns/name Body String Human-readable display name or title of the resource body.
frametrail:tags …ns/tags Annotation Array of Strings Set of free-text tags assigned to the annotation or overlay.
frametrail:uri …ns/uri Annotation IRI (String) Optional dereferenceable URI associated with the item — for example, a Linked Data entity IRI.
frametrail:thumb …ns/thumb Body String (URL or path) Thumbnail image for the resource body. May be a relative path within the FrameTrail data directory or an absolute URL.
frametrail:resourceId …ns/resourceId Body String Reference to a resource entry in FrameTrail's resources/_index.json. Links the annotation body to a managed resource record.
frametrail:attributes …ns/attributes Body JSON Object Type-specific key–value bag. Structure varies by frametrail:type — see §5.
frametrail:licenseType …ns/licenseType Body String License identifier for the resource body. Common values: cc-by, cc-by-sa, cc-by-nc, cc-by-nd, cc-by-nc-sa, cc-by-nc-nd, cc0, public-domain.
frametrail:licenseAttribution …ns/licenseAttribution Body String Free-text attribution string for the resource body's license.
frametrail:events …ns/events Annotation (Overlay) JSON Object JavaScript event handlers for overlay lifecycle events. Keys: onReady, onPlay, onPause, onEnded. Values are JavaScript code strings.

4. Controlled Values for frametrail:type

4.1 Annotation-Level Types

When frametrail:type appears on the annotation object itself, it classifies the FrameTrail item kind:

Annotation Overlay CodeSnippet

Annotation items appear in the sidebar timeline and are grouped per user. Overlay items are spatially positioned over the video using a xywh=percent: fragment selector on the target. CodeSnippet items contain timed JavaScript that executes during playback.

4.2 Body-Level Types (Resource Subtypes)

When frametrail:type appears on the body object, it identifies the kind of embedded or linked resource:

text image audio video pdf youtube vimeo wistia loom twitch soundcloud spotify webpage wikipedia entity location quiz hotspot codesnippet urlpreview mastodon codepen figma

Each body-level type determines how the frametrail:attributes object is structured and which W3C body.type and body.format values are used. See §5 for details.

5. The frametrail:attributes Object

The frametrail:attributes property carries type-specific metadata as an opaque JSON object. Its internal structure depends on the body-level frametrail:type:

Body Type Typical Keys Notes
text text HTML string (duplicated in body.value)
location lat, lon, boundingBox Geographic coordinates (WGS 84) and optional bounding box
wikipedia extract Plain-text extract from the Wikipedia article
quiz text HTML-encoded quiz markup
entity embed Embeddability flag ("forbidden" if the entity IRI blocks embedding)
image, video, audio, pdf (empty or custom) May contain custom metadata added by FrameTrail extensions
youtube, vimeo, … (empty or custom) Platform-specific metadata may be added by extensions

The attributes object is deliberately open-ended. FrameTrail extensions and custom resource types may add arbitrary keys. Consumers should treat unknown keys gracefully.

6. Complete Examples

6.1 Text Annotation

{
  "@context": [
    "http://www.w3.org/ns/anno.jsonld",
    { "frametrail": "http://frametrail.org/ns/" }
  ],
  "type": "Annotation",
  "frametrail:type": "Annotation",
  "creator": {
    "nickname": "jbach",
    "type": "Person",
    "id": "user-42"
  },
  "created": "2025-03-12T10:00:00Z",
  "target": {
    "type": "Video",
    "source": "https://example.com/lecture.mp4",
    "selector": {
      "type": "FragmentSelector",
      "conformsTo": "http://www.w3.org/TR/media-frags/",
      "value": "t=120,180"
    }
  },
  "body": {
    "type": "TextualBody",
    "frametrail:type": "text",
    "format": "text/html",
    "value": "<p>Key argument about open video.</p>",
    "frametrail:name": "Open Video Argument",
    "frametrail:thumb": null,
    "frametrail:resourceId": null,
    "frametrail:attributes": {
      "text": "<p>Key argument about open video.</p>"
    }
  },
  "frametrail:tags": ["open-video", "lecture"]
}

6.2 Image Overlay with Spatial Position

{
  "@context": [
    "http://www.w3.org/ns/anno.jsonld",
    { "frametrail": "http://frametrail.org/ns/" }
  ],
  "type": "Annotation",
  "frametrail:type": "Overlay",
  "creator": { "nickname": "editor", "type": "Person", "id": "editor-1" },
  "created": "2025-03-12T10:05:00Z",
  "target": {
    "type": "Video",
    "source": "https://example.com/lecture.mp4",
    "selector": {
      "type": "FragmentSelector",
      "conformsTo": "http://www.w3.org/TR/media-frags/",
      "value": "t=30,60&xywh=percent:10,15,30,30"
    }
  },
  "body": {
    "type": "Image",
    "frametrail:type": "image",
    "format": "image/png",
    "source": "diagram.png",
    "frametrail:name": "Architecture Diagram",
    "frametrail:thumb": "diagram_thumb.jpg",
    "frametrail:resourceId": "res-diagram-01",
    "frametrail:licenseType": "cc-by-sa",
    "frametrail:licenseAttribution": "J. Bach, 2025",
    "frametrail:attributes": {}
  },
  "frametrail:events": {
    "onReady": "",
    "onPlay": "",
    "onPause": "",
    "onEnded": ""
  },
  "frametrail:tags": ["diagram"]
}

6.3 Location Annotation

{
  "@context": [
    "http://www.w3.org/ns/anno.jsonld",
    { "frametrail": "http://frametrail.org/ns/" }
  ],
  "type": "Annotation",
  "frametrail:type": "Annotation",
  "creator": { "nickname": "geo-editor", "type": "Person", "id": "geo-1" },
  "created": "2025-03-12T11:00:00Z",
  "target": {
    "type": "Video",
    "source": "https://example.com/documentary.mp4",
    "selector": {
      "type": "FragmentSelector",
      "conformsTo": "http://www.w3.org/TR/media-frags/",
      "value": "t=200,260"
    }
  },
  "body": {
    "type": "Dataset",
    "frametrail:type": "location",
    "format": "application/x-frametrail-location",
    "frametrail:name": "Filming Location",
    "frametrail:thumb": null,
    "frametrail:resourceId": null,
    "frametrail:attributes": {
      "lat": 52.5200,
      "lon": 13.4050,
      "boundingBox": "13.088,52.338,13.761,52.675"
    }
  },
  "frametrail:tags": ["berlin", "location"]
}

7. Content Negotiation

The namespace URL http://frametrail.org/ns/ supports HTTP content negotiation. Clients requesting application/ld+json or application/json receive the JSON-LD context document. All other requests (including browsers) receive this HTML page. 

# Fetch the JSON-LD context
curl -H "Accept: application/ld+json" http://frametrail.org/ns/

# Fetch the HTML documentation
curl -H "Accept: text/html" http://frametrail.org/ns/
